# Oh My Posh Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Powerlevel10k with Oh My Posh (catppuccin palette, extended segments, transient prompt) on macOS + WSL, including Claude statusline and Meslo via OMP.

**Architecture:** Vendored theme at `home/.config/ohmyposh/catppuccin.omp.json`; zsh inits via cached `oh-my-posh init zsh --config …`; install via Homebrew core (macOS) / curl script (WSL); fonts via `oh-my-posh font install meslo`; Claude statusline points at the same theme.

**Tech Stack:** Oh My Posh ≥30, zsh, machine_setup.yaml, Brewfile, Ghostty, Windows Terminal

**Spec:** `docs/superpowers/specs/2026-08-15-oh-my-posh-design.md`

## Global Constraints

- Theme base: catppuccin palette/chrome; segment set is the locked list (not stock os/session)
- Segments: path, git, project, node, rust, bun, svelte, aws, claude, status, executiontime
- Keep pane-context / `awsp` / herdr `$aws` (OMP only displays `AWS_PROFILE`)
- `CURSOR_AGENT` early-return stays (no OMP in agent tool shells)
- Font face in terminals: `MesloLGM Nerd Font`
- macOS brew: use core formula `oh-my-posh` (homebrew-core; prefer over old tap path)
- WSL install: `curl -s https://ohmyposh.dev/install.sh | bash -s`
- Do not commit unless the user asks

- [ ] **Step 4: Add Oh My Posh init after PATH is ready, before `unfunction _dotfiles_cache_source`**

Place with the other cached inits (after zoxide/atuin block is fine; must be **before** `unfunction _dotfiles_cache_source`):

```zsh
# Oh My Posh (replaces Powerlevel10k)
if (( $+commands[oh-my-posh] )); then
  _dotfiles_cache_source \
    "${XDG_CACHE_HOME:-$HOME/.cache}/dotfiles/oh-my-posh_init.zsh" \
    "${commands[oh-my-posh]}" \
    oh-my-posh init zsh --config "${HOME}/.config/ohmyposh/catppuccin.omp.json"
fi
```

Note: `oh-my-posh init zsh --config …` writes shell hook code to stdout; caching is valid because output is static per binary+config path. If the config file changes without the binary changing, clear the cache once:

```bash
rm -f "${XDG_CACHE_HOME:-$HOME/.cache}/dotfiles/oh-my-posh_init.zsh"
```

(Document that in the commit message / README touch if useful.)

Optional hardening: include config mtime in cache invalidation by adding a one-liner before `_dotfiles_cache_source` that `rm`s the cache when the omp.json is newer — only if easy; not required for first land.
